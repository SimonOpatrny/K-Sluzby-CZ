# K-Služby CZ – Studio V6

Otevřete `index.html`. V6 přidává fotogalerii s lightboxem a fotografické sekce služeb, o nás a pronájmu.

**DŮLEŽITÉ:** Fotografie jsou ilustrační, nikoli snímky skutečné firmy, jejích zaměstnanců nebo vozidel. Fotografie se načítají z externího Unsplash CDN; bez připojení nebudou fungovat. Odkazy nebylo možné ověřit v běžícím prohlížeči. Před klientskou prezentací zkontrolujte zobrazení a licenci každého snímku a ideálně nahraďte skutečnými firemními fotografiemi. Ceník a podmínky pronájmu musí potvrdit klient. Formulář používá e-mailového klienta.

V10: Galerie je pouze na samostatné stránce galerie.html; všechny odkazy v navigaci a patičce směřují sem.


## V11 fotografie a galerie

Externí fotografie jsou ilustrační, pocházejí z webů třetích stran a nejsou automaticky licencované pro komerční publikaci. Před nasazením získat licenci / vlastní fotografie. Dostupnost vzdálených obrázků není offline zaručena.
